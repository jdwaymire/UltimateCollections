Home screen rows

Shows collections as rows on your users' home screens (Emby 4.10 or newer). Seasonal rows appear when their season starts and hide when it ends, in the spot each user gave them. Rows change when the sync task runs.

Off by default. Using another plugin for home screens (for example Home Screen Companion)? Let only one of them manage collection rows, or users may see a row twice.

Danger zone: delete all collections

This deletes every collection in Emby, not only the ones this plugin made: collections you created by hand, ones Emby created automatically, and ones from other tools or plugins. Use it to clear out a library whose collections have grown out of hand before letting this plugin build them again.

  • Your movies, shows and files are not touched. Only the collections are removed: their names, posters and which titles were in them.
  • It cannot be undone. A list of every deleted collection and its titles is saved first, in the plugin's data folder under backups/.
  • Collections Emby makes automatically from movie metadata (TMDb "box sets") come back on the next library scan unless that is switched off in each movie library's settings.
  • The plugin's own collections are created again on its next run.
